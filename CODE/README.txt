# Autonomous Robotics Software Stack

Personal robotics project focused on autonomous navigation and decision making.

## Overview

This project aims to develop the software architecture for an autonomous mobile robot.

The software is organized into several modules, which will be upgraded from a simple Version (V1) to a more complex aproach (V3):

- Perception
- World Model
- Behavior
- Path Planning
- Motion Execution

The goal is to allow a robot to perceive its environment, build an internal representation of the world and navigate autonomously.

## Current Features

- World model implementation
- Object tracking
- Position and orientation representation
- KD-Tree experiments
- RRT / RRT* path planning experiments

## Technologies

- Go
- Python
- JSON

## Planned Features

- Sensor integration
- Camera-based object detection
- Obstacle avoidance
- Autonomous navigation
- Hardware deployment
- Object detection using an NNE
